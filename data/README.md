# Data

No external data are used. `original_sample.csv` is a reproducible synthetic sample of 100 instrument errors in millimeters. It was generated from `N(0.4, 2^2)` with R seed 6408 and is the original sample used for the bootstrap distribution in Figure 1 and the observed statistic in Figure 3. Parameters and seeds are maintained in `code/simulation_config.R`.

Run `source("code/make_sample_data.R")` from the project root to regenerate the CSV. The analysis script sources the same configuration to generate its sample; it does not read the CSV. Figure 2 additionally generates independent samples inside the coverage simulation, and Figure 3 generates its null samples under mean zero. These simulated samples are generated by `code/simulation.R` rather than stored as large datasets.
