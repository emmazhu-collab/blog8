# Blog 8: Simulation, Bootstrap Confidence Intervals, and Hypothesis Testing

This project contains the reproducible R simulation and simulated sample used for Blog 8. The article itself lives in the main course website project, following the same structure used for Blogs 6 and 7.

## Project contents

| Path | Contents |
| --- | --- |
| `code/simulation.R` | Full simulation, chart construction, and numerical checks |
| `code/make_sample_data.R` | Recreates the included simulated sample CSV |
| `code/simulation_config.R` | Shared population parameters, seeds, and original sample generation |
| `data/original_sample.csv` | The 100-observation simulated sample used in Figures 1 and 3 |
| `data/README.md` | Data-generation details and how the CSV relates to the R script |
| `results/` | Three interactive HTML figures and their required companion folders |

## Data and simulation

There is no external or collected dataset. The project generates synthetic independent observations from a normal population with mean 0.4 mm and standard deviation 2 mm. Shared parameters and seeds are defined once in `code/simulation_config.R`. The 100-observation original sample uses seed 6408. The CSV is included so readers can inspect the example sample; `code/make_sample_data.R` regenerates it from the shared settings, and the analysis script sources those same settings. Figure 2 uses 2,000 fresh original samples and 2,000 bootstrap resamples within each sample. Figure 3 uses 20,000 samples under the zero-mean null hypothesis.

The main simulation seeds are 6408 (original sample and Figure 1 bootstrap), 6409 (coverage experiment), 6410 (null distribution), and 6411 (resampling check). The full script also runs checks on dimensions, confidence intervals, simulated critical values, and the p-value.

## Reproduce the article

You need R and the R packages `plotly` and `htmlwidgets`. Install them once if needed:

```r
install.packages(c("plotly", "htmlwidgets"))
```

Open `blog8.Rproj` in RStudio. The article is maintained in the course website project; this repository contains the code and data needed to reproduce its results. Run all commands below from this project folder.

To recreate the included sample CSV, run this from the project root in the R Console:

```r
source("code/make_sample_data.R")
```

To inspect the full simulation objects in the R Console, from the project root run:

```r
source("code/simulation.R")
results
mean(x)
observed_t
p_value
```

The same command recreates the three interactive charts in `results/`. Open `bootstrap_distribution.html`, `coverage_simulation.html`, or `null_distribution_test.html` in a browser. Keep each matching `*_files/` folder beside its HTML file; those folders contain the chart libraries required for interactivity.

The fixed-seed output includes a sample mean of 0.477 mm, a 95% bootstrap interval of [0.066, 0.893] mm, 95.05% coverage (1,901 of 2,000 intervals), an observed t-statistic of 2.165, and a simulated two-sided p-value of 0.0328. The exact values are generated by the code rather than manually entered in the article.
